# Employee-Management-SQL-Window-Functions
A PostgreSQL Employee Management project demonstrating SQL Window Functions such as ROW_NUMBER(), RANK(), DENSE_RANK(), SUM(), AVG(), MIN(), MAX(), COUNT(), LAG(), LEAD(), FIRST_VALUE(), and LAST_VALUE() for employee salary and department analysis.

📌 Project Overview

Employee Management & SQL Window Functions is a PostgreSQL-based SQL project designed to demonstrate practical knowledge of database creation, employee data management, set operations, and advanced SQL window functions.

The project uses current and former employee datasets to perform data analysis and generate meaningful insights related to employee salaries, departments, rankings, salary comparisons, and employment status.

This project demonstrates the ability to write structured SQL queries and apply analytical functions to real-world business-style employee data.

🛠️ Technologies Used
Database: PostgreSQL
SQL Tool: pgAdmin 4
Concepts: SQL, Set Operations, Window Functions

🎯 Project Objectives

The main objectives of this project are:

Create and manage employee databases using PostgreSQL.
Insert and retrieve employee records.
Compare current and former employee data.
Practice SQL set operations.
Apply ranking functions to employee salaries.
Perform department-level salary analysis.
Calculate running salary totals.
Compare employee salaries using LAG() and LEAD().
Identify first and last salary values within departments.
